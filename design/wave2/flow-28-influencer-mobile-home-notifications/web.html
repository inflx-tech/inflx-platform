What moved + why

Home redesigned around daily action, not wallet
  • Wallet hero OUT of Home — duplicate of Earnings tab UX. Replaced with one-line glance strip at bottom (still shows balance + 1-tap to Earnings).
  • Greeting + count line NEW — "You have N things that need your attention" anchors the user in today's work.
  • 3 attention tiles NEW — Pending Offers / Contracts to sign / Content revisions. Counts derived client-side from already-loaded notifications array, no new endpoint.
  • Active Campaigns preserved — same data binding, just visually upgraded (thumb circle + sub line).
  • Recent Activity NEW — top 3 unread notifications inline. Reuses notifications already loaded for the badge. View All → Notifications screen.
  • MyStore / MyTransactions quick-links removed — they were stat-cards-disguised-as-buttons, low-value. MyStore is reachable from Profile tab; TransactionFeed is reachable from Earnings.

Backend compatibility (verify-twice ✓)

Same 5 APIs · zero new endpoint
  • getEarnings() → wallet glance line only (wallet_balance / available_to_withdraw)
  • getMyCampaigns('active') → Active Campaigns list
  • getNotifications() → badge count + Recent Activity (top 3) + action-tile counts (client-side derived by type)
  • markAllNotificationsRead() → mark all CTA on Notifications screen
  • data_json.{offer_id, contract_id, deliverable_id, negotiation_id} → deep-link routing preserved across 18 type switch branches

StatusPill canonical map +2

Withdrawal lifecycle additions · 37 → 39 total
  • processing → infoPale / info / 'PROCESSING'
  • failed → dangerPale / dangerText / 'FAILED'

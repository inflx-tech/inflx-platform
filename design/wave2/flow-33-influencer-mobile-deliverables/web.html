Backend compatibility (verify-twice ✓)

  • getDeliverable(id) (Screen fallback fetch)

  • getMediaUrl(id) (post-upload preview)
  • submitDeliverable(id, {media_key/submitted_url, notes_to_brand?}) POST
  • submitLive(id, {live_url}) POST
  • refreshStats(id) POST (Apify scrape trigger)
  • uploadFile() direct R2 PUT helper (XHR progress)

SDK boundary (image-picker — already shipping)

react-native-image-picker@7.1.2
  • launchImageLibrary · mediaType:'mixed', videoQuality:'high', selectionLimit:1, includeBase64:false
  • launchCamera · mediaType:'video', videoQuality:'high', durationLimit:300 (5 min)
  • handlePickerResponse · sets selectedMedia {uri, type, fileName, fileSize, width, height, duration}
  • 3-step upload: getUploadUrl → R2 PUT w/ progress callback → submitDeliverable w/ media_key
  • No native rebuild needed — same APK from Flow 28 (NATIVE_RUNTIME=2)

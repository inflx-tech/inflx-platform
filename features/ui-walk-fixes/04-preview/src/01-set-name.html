New set: the name box

You reported that New set opens with "Set A" already typed in the name box. That is true: the app puts "Set A" (then "Set B", "Set C") into the box as real typed text, so you have to rub it out before typing your own name, and a set saved without touching it really is called "Set A". After the change the box opens empty with a grey example, "e.g. Festive sarees", and the keypad does not open by itself; this means every set now needs a name you type, where today a brand can save one without typing anything. It is the same on all three ways into New set, and nothing else on the screen changes.

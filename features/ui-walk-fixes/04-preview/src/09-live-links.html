Pasting the live link turns the button on

You pasted the live link and "I've posted everything" stayed grey. After the fix every link box saves by itself and shows "Saving…", then the tick, or a red line if the link is refused; the button turns yellow as soon as every box is filled and every Story has its screenshot, and pressing it finishes the saving before it marks anything posted.

# Workflow prediction — Bulk Add via Excel

At a leaf the brand sees two tabs: **Add one-by-one** (the stepper) and
**Bulk add (Excel)**.

On the Bulk tab:
1. **⬇ Download template** — a `.xlsx` opens with columns matching *this leaf's
   current specs*: Name · Price · Brand · Stock · Fabric · Pattern · … ·
   Colour · Size · Variant stock. Spec columns that have fixed options show a
   **dropdown**; required ones are marked. A second sheet explains each column.
2. The brand fills rows (one row per colour+size for variants), saves.
3. **⬆ Upload filled file** — a moment later: **"24 products created"** with
   the new SKUs, or a tidy **error list** ("Row 7: Fabric 'Silkk' not allowed;
   Row 12: Price missing") if anything's off — nothing is saved until it's all
   valid.
4. A **Needs photos** strip lists the new products, each with **＋ Add photos**
   so pictures get attached in a quick pass.

If the founder changed this leaf's specs earlier that day, the downloaded
template already shows the new columns — no one has to rebuild anything.

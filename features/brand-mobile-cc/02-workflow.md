# Workflow — brand mobile command center (A6)
## Actor
Brand on the mobile app, campaign already created (creation stays on web).
## Steps
1. Open a campaign → a **stage rail** shows Fund → Roster → Contracts → Production →
   Review → Payout with the current stage highlighted, and **one primary action** below it.
2. A draft / needs-funding campaign shows **"Fund wallet & publish"** → publishes; if the
   wallet is short, offers to open the Wallet tab to top up (mobile already supports top-up).
3. Other stages route to the existing screens: applications / negotiations → influencers
   list (filtered), reviews / live-confirm → review queue, completed → Wallet.
4. Nothing pending → a calm "All caught up" bar.
5. From Alerts → Content, tapping an item now opens the campaign (previously a dead tap).
## Success
- Stage + primary action correct for each status/count; a campaign can be funded+published
  from the phone; the previously-dead tap works; existing tiles/screens still function.
## Failure/edge
- Publish fails → real error alert, campaign unchanged. Cancelled → no action offered.

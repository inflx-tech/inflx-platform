INFLX · Brand apps · post-campaign redesign — shared web + mobile model

One campaign, one command center with stages.

Today a created campaign scatters across 5 web routes + a duplicate action inbox (and the same on mobile), with the fund/publish step missing and money actions hidden in table rows. This replaces all of it with one staged command center — the same "what's the next action" spine we gave the influencer app, shown here on both web and mobile from one model.

1 · The campaign spine — six stages

Driven by campaign status. Each stage owns its actions and its money moment; the rail shows what's done, what's current, and where attention is needed. No more hunting across /influencers, /sets, /reviews, /escrow.

Every money move is a stage's primary action, never a hidden button. Publish (locks budget), counter-sign (locks Tranche 1), confirm-live (releases Tranche 2), completion (releases Tranche 3) each surface as the big CTA of their stage — not a 11px link nested two rows deep in a table.

2 · The command center — web & mobile, one model

Same campaign in the Review stage. Compact stage strip up top, the stage's primary action, the working queue, and a single money panel. The mobile frame is the identical model, stacked.

Brand web — dashboard

Full-width; stage strip replaces the tab-vs-route split. Confirm-live (releases money) is a green CTA, not a nested link.

4 · What it consolidates

✕Routes /reviews, /sets, /escrow → sections of the one command center (Review stage, Roster grouping, Payout panel). Review stops being duplicated inline + as a route.
✕Contract signing in 3 places (list strip, Contracts tab, modal) → one signing surface; the cross-campaign strip becomes a router that deep-links into it.
✕Mobile ActionRequired duplicating per-campaign actions → a cross-campaign router that opens the right campaign's stage (no second code path).
◐The 1,468-line influencers page → roster grid stays; Negotiation, Contracts, and Production become their own stages.
＋Fund & Publish — the missing first step — becomes the stage-1 primary CTA on both web and mobile.
Scope: frontend-only — web (Vercel) + mobile (OTA), re-organizing existing screens over existing publish / wallet / contract / deliverable / escrow endpoints. No backend, no DB. Instagram-clean styling, consistent with the influencer app. Next: the Listing shell mockup (fluid full-width grid, bigger tiles, names below the image, one card system across verticals — web + mobile).

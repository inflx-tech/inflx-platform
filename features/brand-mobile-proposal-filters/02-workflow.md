# Workflow — proposal filters on mobile
1. Proposals inbox → tap **Filters** on the accepting bar.
2. Set min tier / niches / min ER / same-city / past-collabs → Save filters.
3. Settings persist; creators see the criteria before pitching.
## Success
- Filters editable and saved from the phone; no web-dashboard instruction remains.
## Failure/edge
- ER outside 0–100 → blocked with a message. Save failure → real API error shown.

What this rethink solves · the 30-influencer scroll problem

Before · flat scroll (current 1281 LOC)

  • 2 sets visible inline → bad at 10
  • 30 influencer rows × 150px = 4500px of scroll
  • No way to filter "show me only negotiating"
  • No way to find "@priya.cooks" without scroll-search
  • Set context lost mid-scroll
  • Analytics buried below influencers
  • Web dashboard link 6000px below the fold

After · hub view (HUB phone)

  • One summary card with progress + 3 KPIs (always above the fold)
  • Urgent action queue inline (apps / reviews / live confirm) — actionable in < 1 second
  • 6 drill-down tiles (Sets · Influencers · Analytics · Escrow · Content · Conversions) — each shows headline number + sub-stat
  • Brief collapsed by default (tap to expand)
  • Web link visible without scrolling past everything
  • Hub fits in ~3 phone-screens of scroll regardless of campaign size

After · drill-down (Influencers phone)

  • Search by name/handle (yellow focus halo)
  • Filter by SET (chip row with mono counts)
  • Filter by STATUS (chip row with mono counts)
  • Per-card progress + tranches + action button (Open contract / chat)
  • Scales to 30+ rows cleanly because the user filtered down before reaching the list

New screens needed

  • BrandCampaignInfluencersListScreen — drill-down from Influencers tile · search + set filter + status filter
  • BrandCampaignSetsListScreen — drill-down from Sets tile · set cards with embedded influencer mini-roster + funnel for open calls
  • BrandCampaignReviewQueueScreen — drill-down from Content tile · combines content-awaiting-review + live-confirm into one focused queue

Existing screens reused (no new)

  • BrandConversions — already exists, takes campaignId param · used for Conversions tile drill-down
  • BrandContract — already exists · used from influencer card "Open contract"
  • BrandNegotiation — already exists · used from "Open chat"
  • BrandInfluencerProfile — already exists · used from application "View profile"

Inline (no drill-down) on the hub

  • Analytics tile shows summary; tap could open a future dedicated screen OR open BrandConversions for now
  • Escrow tile shows summary; tap could open a future dedicated tranche screen OR open wallet for now
  • Pragmatic: stub these two tile-taps to navigate to the existing closest screen until dedicated screens are built
Scope honesty: this is bigger than my original Flow 5 (just restyle). It's a structural restructure + restyle + 3 new screens. Realistic effort: 6-10h focused work (vs ~3h for restyle-only).

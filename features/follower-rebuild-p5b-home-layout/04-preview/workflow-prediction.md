# 04 — Workflow Prediction: Phase 5b Home Layout

**Locked mockup:** `mockups/home-recolored.html` (Screen 1 — Home).

Expected follower-visible end state after 5b ships (OTA, flag already on):

1. Home opens → header (location · bell · avatar) → greeting → search row.
2. **Category bubbles** render as a horizontal row of circular emoji bubbles
   (Fashion/Food/Beauty/Furniture/Car Rentals + More), gold-active.
3. **Top Influencers** story rail (existing) under a clean "View all" header
   (no colored tag chip, no count pill).
4. **Hero banner** (when admin has placed a hero offers shelf): cream band, a
   terracotta eyebrow, a serif headline showing the discount/brand, a gold
   `SHOP NOW` button with **ink** text, and a limited-time badge → tap opens the
   offer's ProductDetail.
5. **Top Brands / Top Picks / Popular Near You** carousels under clean headers,
   each with a working "View all" → Section Results (unchanged).
6. **Trust band** (Authentic · Returns · Secure) above the bottom nav.
7. No white text on any gold surface in the Home chrome.

Functional flows (navigation, tracking 4-ID pass-through, follow, View-all
Results) are unchanged — this prediction asserts visual structure only.

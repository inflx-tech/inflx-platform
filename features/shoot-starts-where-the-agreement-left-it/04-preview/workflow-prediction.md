# Prediction

1. Open Asha's collaboration on either phone. The shoot reads **Store visit**, status **A time is
   on the table**, with **no time set yet** — not "done".
2. Brand fills the store address (and optionally a time). Creator sees it and proposes or accepts
   a slot. Either can counter, twice per side.
3. Once accepted the visit is **Settled**.
4. The visit happens. **She** marks it done → her screen says it closes once the brand marks it
   too. **The brand** marks it done → the shoot is complete.
5. Content comes next.

## For a remote collaboration

1. The shoot reads **Remote**, status **Settled** — nothing to arrange.
2. **She** marks it done. That alone finishes it.
3. The brand never sees a mark-done button, and is told why.

## What must NOT happen

- Any event appearing as `completed` that no person marked.
- A store visit closing on one side's tap.
- A brand marking a remote or shipped shoot done.
- A shoot opening in a mode the agreement did not settle, when the agreement settled one.
- A genuinely completed practice visit being reopened.

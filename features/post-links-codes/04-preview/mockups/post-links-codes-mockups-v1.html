Rules built into these screens
  • Five channel endings: /ig Instagram · /yt YouTube · /wa WhatsApp · /fb Facebook · /o Other (X, LinkedIn, Telegram, SMS…). Every ending opens the same thing; it only tells INFLX where the visit came from.
  • A post's code and links appear the moment INFLX approves it. Before its posting date they open a "goes live on 10 Oct" page. Posts in review or drafts have none.
  • Code: 6 letters and numbers, no vowels, no look-alikes (0/O, 1/I), capitals don't matter. One per post, never changes.
  • The old offer code (name + 3 characters) is retired. The post code does its job.
  • Follower side (rule only, screens come with the shopper app): typing a post code in INFLX search shows exactly that post, with its products and offer applied. A link opens the post in the app, or a web page with "Get the app" if INFLX isn't installed. A removed post's link opens her store.
  • The channel is reporting only: an item is labelled with the latest tap on that creator's links in the last 30 days, otherwise "In INFLX". Who gets paid never depends on it.

# Prediction

| Step | Prediction | What I predict goes wrong first |
|---|---|---|
| W1 publish with no offer | Goes through, one warning | — |
| W2 offer on her row clears it | Clears | **The likeliest miss.** Two places compute this now — the phone before publish, the server after. If they disagree, a brand watches a warning vanish and reappear |
| W3 one control | Clean | — |
| W4 preview | Opens, priced on her commission | **Never exercised.** No creator has ever carried an offer, so this basket has never been priced from a real per-creator one |
| W5 real refusals | Still refuse | **The one that matters.** Relaxing one rule next to four others is exactly how a fifth goes quiet |

## Most likely to be wrong

**That the phone and the server agree about what counts as "has an offer".** The phone reads a
local draft; the server reads rows. Before publish only the phone can be right, which is why the
server's copy is suppressed — but the moment it publishes, the server's view takes over.

# 02 — Workflow: Follower Order Tracking

1. Follower → Orders → tap an order (or Confirmation → VIEW ORDER) → OrderDetail.
2. Sees: Order # + status + via @creator → 5-step timeline (each step's real date,
   courier shown on the Shipped node) → Shipment (courier + AWB + Track ↗) → items +
   total → delivery address.
3. As the brand advances status (Unit 2), the follower's timeline reflects it (+ push).
4. Delivered + online_order → Request Return CTA (within window).

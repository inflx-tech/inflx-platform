Almost all of this already existed. Bulk intake, the admin-supplied city, the automatic scrape fan-out, and the column protection that stops the scrape overwriting a manual value — all shipped. The only missing piece was state.

The tag cannot be overwritten. state is deliberately kept out of the ingest allow-list, so a re-scrape structurally cannot touch it. city sits in that list and is protected only by n8n convention; the tag is the whole feature, so convention was not enough.

No hard-coded Telugu-states list. The dropdown is built from what has actually been tagged and sorted by creator count, so Andhra Pradesh and Telangana rise to the top on their own — and adding Karnataka later needs no code change.

Creators with no location are hidden from area searches (founder's call). They remain findable by tier, niche, followers and name.

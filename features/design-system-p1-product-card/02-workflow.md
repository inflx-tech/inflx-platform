# Workflow — design-system-p1-product-card

1. Brand uploads a product photo → crops to the 3:4 frame → what they set is
   what shows (the card no longer re-crops it).
2. Follower browses a category → grid shows clean 3:4 cards (image, badge,
   brand, name, price/struck) — identical style to the home rails.
3. Follower taps "view all" (SectionResults) → same clean 3:4 cards.
4. Every product surface now reads as one consistent, professional grid.

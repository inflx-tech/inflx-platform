Backend-source audit · Flow 6 · Brand web · Campaign detail

Reuses Flow 5 endpoints (same backend, no new)

  • campaignApi.get(id) → deep join: sets[] · influencers[] · deliverables[] · tranche_statuses · deliverable_counts · transaction_count
  • campaignApi.getLive(id) → enriched real-time view (used for Content tab today; will be the Reviews sub-route data source)
  • campaignApi.getEngagement(id) → totals + by_influencer
  • campaignApi.getConversions(id) → summary.{total_transactions, total_revenue, total_commission}
  • campaignApi.get(id + '/products') → products[] with published_by + assigned_to_influencers

Hub tile audit (all backed)

  • Progress % · Σ ci.deliverable_counts.{live+approved} / Σ .total
  • Budget % · Σ ci.agreed_fee / campaign.total_budget
  • Active count · flatMap(sets, s=>s.influencers).filter(active|live).length
  • Reach · engagement.totals.total_likes
  • Avg ER · engagement.totals.avg_er
  • Sets · sets.length + open_group count
  • Influencers · flatten count + status breakdown
  • Content · Σ dc.live / Σ dc.total + queue count
  • Escrow · escrow.entries.filter(status).reduce(amount)
  • Conversions · conversions.summary.*
  • Publishing · productsData.products.filter(published).length

Web-specific preserved (NOT moved to sub-routes)

  • ContractModal — inline contract signing with clauses + notes + content requirements + brand-sign flow. Triggered from per-influencer row on Influencers sub-route. Stays as modal.
  • NegotiationModal — inline negotiation chat. Triggered from per-row "Open chat". Stays as modal.
  • ProductionPanel — production scheduling for shoots (web-only feature, doesn't exist on mobile). Lives inside ContractModal; stays.
  • MediaPreview — deliverable content preview with R2 signed URL. Used in Reviews sub-route.
  • DeliverableStatsCard — engagement stats with refresh button. Used in Reviews sub-route.

Tab → sub-route migration

  • tab "overview" → Hub view at /[id] (this redesign)
  • tab "content" → /[id]/reviews NEW sub-route
  • tab "products" → keep as INLINE Publishing tile + drill-down OR NEW /[id]/products
  • tab "analytics" → INLINE on hub (4-tile mono grid) + link to /dashboard/conversions for full view
  • tab "conversions" → drill tile → /dashboard/conversions?campaign=X (already exists)

New sub-routes (3)

  • /dashboard/campaigns/[id]/influencers/page.js — full influencer list with search + Set/Status chips + per-card actions. ContractModal + NegotiationModal triggers live here.
  • /dashboard/campaigns/[id]/sets/page.js — set cards with goal badges + mini-roster + funnel for open_group
  • /dashboard/campaigns/[id]/reviews/page.js — content review + confirm live tabs (MediaPreview + DeliverableStats inline) + handle Review + ConfirmLive actions

Existing sub-route kept

  • /dashboard/campaigns/[id]/escrow/page.js — already exists (155 LOC); restyle to locked palette only

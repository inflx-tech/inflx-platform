Rules behind these screens

TopicRule
CampaignName (required, ≤60) and description (optional, ≤200, never shown to creators). Holds one or more sets. Complete only with at least one set.
SetName (required, ≤60, shown to creators), Aim (one of three), mode of work (Store Visit or Remote), branch (required for Store Visit), posting date. No money or delivery terms: those are per creator in item 5.
DatesThe date picker offers only dates at least 7 days ahead, so no "too soon" error can happen. Invitations close at posting date − 3 days; the cutoff shows in the picker, on the form and on every set screen. The server checks the rule again.
BranchesThe registration store address is the first branch, marked "Main branch". A Store Visit set names one branch; creators see its city. The exact address goes with the shoot plan.
StatesDraft (nothing sent) · Live (first invitation sent) · Completed (every collaboration ended) · Expired (nobody signed by the cutoff). A campaign follows its sets.
LocksOn the first invitation: Aim, posting date, mode and branch lock. The set name stays editable. Creators can be added until the cutoff and removed until they sign.
DeleteA draft set with nothing sent can be deleted. A campaign can be deleted only while every set is such a draft. No manual cancelling after invitations are sent.
ExpiryAt the cutoff with no signed agreement: the set expires, open invitations close, creators see "Expired", the set hides behind "Show past sets". A set with at least one signature carries on; unanswered invitations expire on their own.
Past dateA draft whose posting date has passed shows "Date passed" and can't invite until a new date is chosen.
DuplicateCopies name, Aim, mode and branch into a new draft set in the same campaign with a new date. Never copies creators, invitations or agreements.
From a groupA campaign started from a creator group (item 3, G10) shows the group on the new campaign and carries its creators into the first set's picker. Nothing is sent until invitations go out.
ProgressCampaign and set cards show invited, signed and waiting, plus "· {n} declined" when anyone declined or let an invitation expire. Invited counts everyone ever invited, so the bar does not fill when people said no: green for signed, blue for waiting, grey for the rest.
MoneyNo money in this item. The INFLX campaign fee applies to Pay for Content only and is charged when funds lock at signing (item 9).
Placeholders"Add creators" shows "Coming soon" until item 5. The creator list inside a set arrives with item 5.
States on listsLoading, empty and couldn't load, as in items 2–3.

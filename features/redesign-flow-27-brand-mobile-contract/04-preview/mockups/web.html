Flow 27 · brand-mobile Contract — wave2 mockup

Largest screen in the bucket (1341 LOC) and the finale of mobile-brand. Drives a 4-state contract lifecycle (draft → pending_influencer → pending_brand → active) plus a nested BrandProductionPanel running a 3-mode × 6-state visit/shipment/remote state-machine. Zero SDK boundaries — pure React Native primitives, signatures are display-only (backend handles signing event), PDF is a separate screen, dates use a local DateTimeChipPicker. Restyle scope: brandPalette + fonts + StatusPill (extend canonical map by 3 entries: proposed/confirmed/in_progress). Production-mode icons swap from emoji to mono-bracket [VISIT] [SHIP] [REMOTE] per bucket convention. All API shapes, all state-machine branches, all wallet-lock math preserved byte-exact.

  • Production panel: mode=null (setup picker) · mode=remote (static notice) · mode=visit (6 sub-states) · mode=shipment (4 sub-states) · cross-cutting flip banner
  • Visit sub-states: no-location · location-no-slot · influencer-proposed · brand-proposed · confirmed (+ reschedule) · completed
  • Shipment sub-states: proposed-waiting · confirmed-dispatch-form · in_progress-tracking · completed
  • Conditional rendering: showFee / showCommission driven by goal (engagement / hybrid / conversion); brand-sign Alert messaging branches on conversion vs others

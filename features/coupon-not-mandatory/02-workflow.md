# The walk

## W1 · The screen he was on

1. Build a commission campaign. One set, one creator. **Set no coupon prefix.**
2. Allocate what she can sell. Review. **Publish.**
3. **It goes.** No "Could not brief Sneha R."

## W2 · A coupon still works when you want one

1. Same again, but set a **coupon prefix** on the set.
2. Publish. Each creator gets a generated code — `PREFIX_FIRSTNAME`, unique.

## W3 · An open group publishes without a prefix

Build an open-group commission set with no prefix. **It saves and publishes.**

## W4 · A content set still refuses a prefix

Try to set a coupon prefix on a pay-for-content set. **Still refused** — nothing is being sold,
so there is nothing for a coupon to discount.

## W5 · The sale still finds her

⚠️ **This is the one that matters, and it needs the follower app.**

Publish a campaign with **no coupon anywhere**. Open the creator's link as a shopper, buy
something, and confirm the sale is attributed to **her** — brand, campaign, set, creator.

Sixteen sales in production already do this with no coupon in the system, so it should hold.
Seeing it happen once is worth more than the count.

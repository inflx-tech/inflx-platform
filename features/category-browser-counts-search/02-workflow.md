# Workflow — category-browser-counts-search

1. Follower opens the category browser (e.g. from a banner tap).
2. Left rail lists subcategories, each with "N items" beneath the name.
3. Follower taps the ⌕ in the header → the Find/search screen opens.
4. Counts reflect live products (approved brand, active, pushed to store) across
   each category's subtree.

# Workflow prediction — item 20, a creator who owns a brand

**New creator, same number as his brand:** signs in to the creator app → name and city → social
accounts → step 3 shows "This number also has a brand account" with his store's card → "Yes, link my
brand" → he is in the app (under review, as today). The brand app shows a notice: "{Name} linked his
creator account".

**Brand on another number:** step 3 → "Yes, I run a brand" → types the brand's number → "Send code" →
the code arrives on the brand's phone → types it → "Link my brand" → linked.

**Later, from Profile:** Profile › My brand → the same steps → the row reads the brand's name and
"Linked".

**Posting:** once INFLX has approved his creator account and the brand is approved → Create › Create
shoppable post → his brand is first, marked "Your brand" → Next → "What kind of post?" with the
store's own counts → offer or price → products → theme → media → tags → Review reads "For {brand} ·
your brand" → Send to INFLX → INFLX approves → code and links appear; it is in the shop.

**Where he shared it:** on the live post → "Add a place" → Instagram reel → paste the link → Save.
Stats: visits, orders, sales; under Instagram, "Reel · 8 Oct".

**A sale:** a shopper buys through the post → the brand's Wallet › Sales money lists it as "Your own
post {code}" with Shopper paid, INFLX's share, Your share → after delivery and the return window the
share is added to the brand's wallet. Nothing appears in the creator's wallet.

**Removing:** the brand opens Profile › Linked creators → Remove → confirm → his live posts stay; in
Create his brand is gone; a draft for it can no longer be sent. He gets "{Brand} removed your link".

**Edge cases:** a number with no brand account ("No brand on INFLX uses this number."); five wrong
codes (the try ends; start again); a second brand while linked (refused: remove the link first); the
brand still under review (linked, but posting waits for INFLX to approve the brand); his creator
account under review (linking works; Create stays locked as for everyone); an offer that ends (the
post leaves the shop, as any post does); a price-post product that enters an offer (it can no longer
be picked; a post already live keeps selling it at its normal price, as today); the link removed
while a post is with INFLX (INFLX cannot approve it: "…link to this brand was removed").

## The full runs (10 Oct 2026)
- **Baseline** — the committed code (HEAD c21318f7) on an untouched copy with its own database: 150 suites, 2,110 tests, 1,905 passed, 177 failed (the known older failures).
- **First run on the new code** — 151 suites, 2,140 tests: 30 new, all passing; **1 newly failing** (`offer-delete.test.js`, the guard that only the brand's own lists may read an offer's deleted mark). The fault was in the new code; it was fixed there and the test left as it was (`06-diff/notes.md`).
- **Second run, after the fix** — 151 suites, 2,140 tests, 1,935 passed, 177 failed: **30 new all passing, 0 newly failing, 0 gone, 0 newly passing**; the 177 are the same 177.
- **Phone** — 121 suites, 2,897 tests, all passing (`ownBrand20.test.js` 33 new).
- **Production, read-only** — `scripts/run-206.js --dry`: 8 new-kind posts and 17 order lines, none of which the loosened rules would refuse; 5 numbers hold both a brand and a creator account. Nothing written.
- **Not done here:** the website pages were checked to parse, not opened in a browser; the phone screens are proved by mounted tests, not on a device. The device walk of these checks is the founder's.

# 02 — Workflow: Admin order oversight

1. Admin → Orders → sees every brand's online orders (filter by status, search by
   customer/brand/order#/AWB).
2. Expand an order → ship-to, courier/AWB (+track link), commission state, fee.
3. Admin controls: override status (any step) + optional courier/AWB → Apply (notifies
   the follower); or Cancel order.
4. Refunds: handled in the admin Returns queue → marking a return refunded reverses the
   influencer's held commission + marks the transaction refunded.

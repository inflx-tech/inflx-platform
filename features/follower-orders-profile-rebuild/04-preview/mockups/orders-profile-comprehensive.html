⚙️ Admin control hereminimal — these are user-data screens
Orders & Profile · controlmostly the follower's own data
Unlike the discovery screens, these are driven by the follower's own data (their orders, bookings, wallet, saved, following). There are no merchandising shelves to configure — so no Section Manager here.

The few things admin / feature-flags control:

  • Refer & Earn the promo banner copy + on/off (ties to your referral model)
  • Wallet show/hide until the follower-wallet backend lands
  • Returns show/hide per the returns feature flag
  • Menu rows which optional rows appear (Wallet/Returns/Help)

Everything else is data: order status from the live order/booking record · tracking timeline from fulfilment · wallet balance from follower wallet (scaffold) · stats counted from the user's records. Each "via @creator" keeps the 4-ID attribution from the original order.

Note: the order/booking/return flow screens (cart → pay → confirm, enquiry, search) already exist and were repainted in Flow 52 — linear flows, not section screens.

📋 What Orders coversone inbox, five transaction types
Every way a follower transactstabs: Active · Orders · Bookings · Visits · Enquiries · Returns · History
ORDER
Online orders — food / fashion delivery. Live tracker → Track, Reorder, Invoice.
BOOKING
Bookings & rentals — tables, salon/service slots, car & bike rentals. Date/time + QR/ref → Reschedule, Cancel, Directions, Rebook.
PAY-AT-STORE
In-venue payments — paid-at-restaurant/salon/store. Amount + savings + invoice → Rate.
ENQUIRY
Enquiries / leads — halls, wedding planners, big-ticket. Status: Sent → Replied → Closed → View thread.
RETURN
Returns & refunds — fashion returns. Status: Requested → Pickup → Refunded (to wallet).

Each maps to a real record (orders · bookings · follower_transactions · enquiry_leads · returns) and keeps the original 4-ID creator attribution. All ✅ buildable from existing data.

# Workflow — category-browser-drill-nonempty

1. Banner tap opens CategoryBrowser at "Men".
2. Left rail = Men's subcategories (Topwear, Bottomwear, …); right grid = all
   Men's products (subtree). Not empty.
3. Tap Topwear → rail = Tees, Polo, Shirts…; grid = Topwear products.
4. Tap Tees (leaf) → grid = Tees products + facets.
5. Same at any depth; if a node has deeper branches, its subtree products show
   until a leaf is chosen.

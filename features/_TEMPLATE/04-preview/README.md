# Mock UI / Screen Preview (Step 4)

Drop the pre-coding visual previews here BEFORE implementation:

- static HTML mockups, exported design images, or annotated screenshots
- one file per screen/state in the workflow

These are reviewed at the Step-5 lock. After implementation, the
real before/after screenshots land in `qa/artifacts/screenshots/`
and are diffed against these previews in the QA report.

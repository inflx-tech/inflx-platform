# 02 — Workflow

1. Tap a product → product page (image, name, price, variants, Add to cart — unchanged).
2. **Highlights** block: a grid of spec tiles (Colour, Material, Brand, Fit, …) — the key
   attributes the customer scans first.
3. Tap **"View details ›"** → a bottom sheet:
   - **All details** — every attribute as tiles.
   - **About this product** — the full description.
   - ✕ to close.

# 02 — Workflow

## #1 "All"
1. Fashion home → category rail → tap **All**.
2. Opens the category browser titled "All categories": left rail = the world's top
   categories (drilled into the first), right = products + filters. Stays in-world.

## #3 Filters
1. Category browser → tap **Filters**.
2. A clean bottom sheet: grab handle, "Filter & sort", Sort pills, a section per facet
   with rounded value pills; selected = solid pink; Cancel / Apply.

# Workflow — brand daily operations on mobile

1. Brand opens app → Home quick actions now include Orders, Bookings, Offers,
   Meals (restaurants only), Creator market, Plan & billing.
2. **Morning flow:** Bookings → pending tab → confirm/reject each (customer
   notified, list refreshes, stats update). Orders → see yesterday's walk-ins
   and online orders with full money breakdown per row.
3. **Restaurant flow:** Meals → Today board (confirmed orders, prep summary,
   capacity) → mark orders delivered as they go out; Deals tab → accept or
   reject AI-suggested meal deals, archive stale ones, generate new
   suggestions.
4. **Marketing flow:** Offers → create a percentage/flat discount → activate →
   publish to store; check where an offer is attached before archiving.
5. **Admin flow:** Plan & billing → see plan, cycle, usage bars; open invoice
   PDFs; connect payout account once bank details exist (or jump to Wallet).
   Changing plan opens the web dashboard.
6. **Scouting flow:** Creator market → filter tier/city → see counts, rates,
   leaderboards → tap a creator → existing influencer profile screen.

Expected end state: every listed action works on the phone against the same
backend rows the web dashboard reads; nothing on mobile can create listings or
campaigns (founder's two exclusions hold).

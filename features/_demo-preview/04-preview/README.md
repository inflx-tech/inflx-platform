# Preview (Step 4) — _demo-preview (showcase)

The two mockups in `mockups/` and the workflow-prediction beside
them are the demo. Run:

```
pnpm preview:open _demo-preview
```

…to see how the preview-machinery renders them together. This is a
permanent showcase — never reviewed for lock, never released.

## What the founder should see

- A yellow **DEMO — never released** badge.
- Mockup 1 (mobile portrait, 380×720): follower public browse with
  city header, deal cards, sign-in CTA.
- Mockup 2 (desktop wide, 1200×720): brand-web search results with
  both Verified ✓ and unbadged creator cards.
- Workflow prediction (markdown rendered): trigger / steps / end
  state / edge cases / what-changes / blast radius for the Q1
  follower public browse feature.

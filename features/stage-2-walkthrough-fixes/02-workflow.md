# Stage 2 walkthrough — Batch A · the walk

The founder builds two sets and compares them. That is the whole check: one path should feel
noticeably shorter, and the other should feel **exactly as it did before**.

---

## W1 · A commission set (the short path)

1. Campaigns → **New campaign**. Name it, tap the start date.
   → **A calendar opens.** No typing. No `YYYY-MM-DD` box.
   → **No lock note** under the date. The screen ends at *Add the first set*.
2. Add a set → pick **Pay per sale** → **Basics**.
   → **Set name · Starts · How they will drive traffic · Back/Continue.** Nothing else.
   → No *Ends · Never*. No *Budget*. No *Minimum channels*. No *No "who posts?"* note.
   → Channels shows **Instagram and YouTube only**.
3. **Creators.**
   → No *N hidden — wrong aim* chip. Instead, one plain sentence under the heading saying the
     others agreed a different kind of deal.
   → No *Go and ask someone new* button.
4. Tick creators → **Continue** → **Terms**.
   → Allocate what each creator may sell.
   → **Do not pick an offer.**
   → **Save this set is black and works.** No red line underneath.
5. Save. The set exists with no offer.

## W2 · A pay-for-content set (the untouched path)

Build one. **Everything must be exactly as it was:**

* *Posting window from → To*, both now calendar pickers
* **Budget**, showing the calculated figure
* **What you are buying** — the reel/story/post counters
* The wallet still refuses to publish under-funded

⚠️ **This is the walk that matters.** Batch A cannot break the commission path — it only removes
from it. The risk is that a removal leaks into the content path, and the first sign would be a
missing budget or a campaign that will not publish.

## W2b · A "Both" set — the third aim

Build one. It is the only kind that a mistake in EITHER branch can break, because it counts as
both selling and buying content. It must show:

* **Budget** — it owes a fee
* **Both halves of the posting window**
* **What you are buying** — the reel and story counts
* **The channels question** — it sells too
* **Compulsory allocation** at step 4 — she sells, so she must know what she may sell

And it must NOT show minimum channels, the "no who posts?" note, or an offer gate.

## W3 · Add an offer afterwards

Open the saved commission set, pick an offer, save again. It must attach. Optional means
*optional*, not *skippable and then unreachable*.

How this table was produced. A script walks the screen file, finds every section heading, works out which condition encloses it, and resolves that for all three aims. If the code changes, the table changes with it — it cannot drift into being a nice-looking lie.
18 checks now hold this in place, proved by breaking it five ways on purpose — including making “Both” stop counting as a selling set, and moving the Budget block behind the wrong condition. All five were caught.

# The brand's Creators tab, reshaped

Founder, 2026-08-25, after using it: *"collabrations start in two ways, pitches from
creators and invitations from brand … brand can see both in two tabs … find creators screen
need UI changes like filter should not be like that it should popup from bottom … also
design which can handle all three types of ask from brand clearly. UI is not ok."*

## The shape

A collaboration starts **two ways** — she pitches, or the brand invites. After that they
are identical: terms going back and forth, ending agreed or closed.

So **direction is visible while it matters and stops mattering once it does not.**

* **Talking** splits into **Sent** and **Received**.
* **Agreed** keeps its own tab — a settled deal waiting to be briefed is not a
  conversation, it is work for the brand.

Four tabs stay: **Talking · Agreed · Find · Groups**, with Sent/Received a switch inside
Talking. The founder chose this over five tabs, which would truncate on a phone.

### Correcting my own earlier decision

Talking merged both directions deliberately — I argued a brand should not check two places.
The founder used it and said the opposite, and he is right: a request you sent needs
chasing, an approach you did not ask for needs a decision. Merging them hid that.

## Find

Three filter rows occupy the top third of the screen whether or not they are doing
anything, and each opens its own page.

* **Search on top.**
* **Active filters as chips**, removable with one tap. With nothing filtered the top is two
  lines instead of five.
* **One bottom sheet** for all three filters, each option carrying a real count, applied
  together. The button reads **"Show 4"** — the honest version of Apply.
* Nothing applies until confirmed, so a combination can be explored and backed out of.
* The separate **Where picker page is retired**; its counts move into the sheet.

## The three ways to ask

They already share one composer. What they never shared was showing **who**.

**One rule: the button always names who, and how many.** Never "Ask" alone.

| Way | Button |
|---|---|
| One creator | Ask Priya |
| Several ticked | Ask 3 |
| Everyone matching | Ask all 14 |
| A group | Ask AP fashion · 6 |

In Find: nothing ticked → **Ask all N**. Something ticked → **Ask N** plus **Save as
group**, which appears only at the moment it means anything.

## Empty states

Three of these tabs are empty on production today — 0 pitches ever. An empty tab that does
not explain itself reads as broken, which this stage has already produced once with
"Archived". Received, Groups and no-results each say what they are for.

## Out of scope

Selecting several agreed creators to build one campaign from them — that is Stage 2.
Drawn on the boards, deliberately not built.

## No backend work

Every number is already computed and already sent: city and niche counts, tier bands, whose
turn it is, the expiry clock. This is a rearrangement of what the apps already receive.

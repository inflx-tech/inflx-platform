Design language (proposed lock)

brandPalette + creator vibe via content
  • Chrome = light brandPalette — white cards, ink text, #E4E4E7 borders, #FAFAFA bg. Same as brand+influencer apps.
  • Primary = ink+yellow — every CTA is ink-bg + yellow-text Outfit-Black UPPERCASE (or yellow-bg + ink on dark heroes).
  • All money/IDs = JetBrains Mono. Display/headings = Outfit. Body = Plus Jakarta Sans.
  • Creator vibe = content, not theme — yellow story rings, ink/yellow creator avatars, "X's deal" yellowPale strips, creator-note quotes on cards. The soul, carried everywhere.
  • Per-business accent = wayfinding only — restaurant/fashion/beauty/car pale tints on category tiles + card hero + store hero. NEVER on chrome, text, or CTAs.
  • Tab bar — light, yellow active pill behind the icon.

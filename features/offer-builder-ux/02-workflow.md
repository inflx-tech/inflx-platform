# Workflow — offer-builder-ux

## Discount
1. Brand picks offer type = Discount.
2. **Applies to** shown FIRST: Whole store · Category · Products.
3. If Whole store or Category → value shows **"% off"** only (no ₹ toggle).
   - Category → searchable list of the brand's real sections.
4. If Products → **% / ₹** toggle appears + a searchable product finder
   (type name/SKU, grouped by section, tap to add; chips with ✕ to remove).
5. Enter value → preview line updates → save.

## Volume
6. Type = Volume → **Applies to** FIRST (store/category/products, same picker).
7. Then spend tiers (min spend → % off), add/remove tiers.

## Bundle / Free gift / BOGO
8. Product slots use the same searchable finder (single-select for BOGO buy/get
   and free-gift main/gift; multi for bundle).

## CTA hint
9. A hint line states where the offer applies: "Applies to online orders" (all
   scopes) and, for store/category/product scopes, notes pay-at-store bills
   honor store-wide % only.

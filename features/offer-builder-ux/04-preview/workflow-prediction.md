# Workflow prediction — offer-builder-ux

- Discount + Volume ask **Applies to** first, then the value.
- Value type is scope-gated: Whole store / Category → "% off" only;
  Products → % / ₹ toggle.
- Category scope shows a searchable list of the brand's real sections.
- Every product slot (discount/volume/bundle/free-gift/BOGO) uses a searchable,
  section-grouped finder with price; multi-picks show removable chips.
- A CTA hint states where the offer applies (online vs pay-at-store bill).
- Saved payload JSON is unchanged; existing offers open/edit identically.

What changes. Approve/Reject are removed from this page — /admin/approvals becomes the only decision desk. A pending row now links there instead of duplicating the decision with different reason-capture UX.

Reinstate appears for suspended and rejected rows and sends { status: 'approved' }. The backend already accepted this without checking the current status, so no API change was needed — only the button was missing.

Suspend keeps its provenance. Suspending previously shared a code branch with reject and nulled approved_at / approved_by, so the original approval trail was destroyed before you could ever reinstate. The branch is now split.

Unchanged: Fee, row-click navigation to the brand detail page, and the canAction / canFee RBAC gates.

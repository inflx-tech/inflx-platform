B1 · Brand app — Campaigns tab

Every screen in the tab, and every control on it — search, filters, sticky buttons, empty states, pickers. NEW did not exist · CHANGE exists and moves · KEEP unchanged.

A set is one aim, one posting date, one shoot mode. Everything else is per creator.
Posting date ≥ today + 7 · invitations close 3 days before · a store visit finishes 1 day before.
Disagree on the date or the mode → she leaves the set → you disagree (it ends) or defer her → later you build a new set from the deferred.

Two things the data says before we build.

Language is empty on all 25 creators. The filter can be built and will match nobody until creators can set it — which means the creator's profile needs a language field first. It is in B7, not B1.

Engagement rate was deliberately removed from creator search once, with a written reason: "a brand looking for someone to work with does not think 'show me people above 3.2% engagement'." You have asked for it back. I have drawn it as four coarse bands rather than a number box — same information, no false precision.
What this tab costs. Six new screens, sixteen changed, four untouched.

The heaviest is step 2 of the wizard — it gains the mode and one date, and sheds three things to the creator.

The riskiest is the deferred pool — the only place in the app where a creator moves between sets, and where a set gets built out of people rather than the other way round.

Nothing is deleted. The two-step brief and the mode switch vanish as flows, but no screen file goes.

What this tab really costs. Three new screens, fifteen changed, four untouched. The heaviest single screen is step 2 of the set wizard — it gains the shoot mode and one posting date, and loses three things that move to each creator.

The riskiest is "she countered the date or the mode". It is the only screen here that moves a row from one set to another, and nothing in the app has ever done that.

Nothing is deleted. The two-step brief and the mode switch vanish as flows, but no screen file goes — the screens that carried them are reused.

# The walk

1. Campaigns → open any campaign.
2. **The six-stage strip is gone.** No `Fund · Roster · Contracts · Production · Review · Payout`.
3. The primary action button is still there and still right:
   * a **draft** campaign → *Fund wallet & publish*
   * one with applications → *Review N applications*
   * one with live URLs pending → *Confirm N live URLs*
   * nothing pending → *All caught up*
4. Tapping it still goes where it went before.
5. Campaign progress, the budget/active/reach figures and the Explore tiles are unchanged.
6. Drill down: sets → creators → her six steps. **That** six is the only six left in the app.

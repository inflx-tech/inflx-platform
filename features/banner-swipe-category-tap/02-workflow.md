# Workflow — banner-swipe-category-tap

1. Admin adds a Full-width banner, uploads 3 images, sets each tile's tap → a
   category (picks the exact node).
2. Follower sees the banner and SWIPES between the 3 images (dots track
   position).
3. Follower taps → CategoryBrowser opens at that category: left rail of
   subcategories + right grid of products (the Blinkit view), not a tiles page.
4. Single-image banner: static, unchanged.
5. Hero slider: still auto-advances (the difference from Full-width banner).

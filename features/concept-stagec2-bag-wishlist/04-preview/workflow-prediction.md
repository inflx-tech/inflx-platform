   no login). Shop-sheet cards grow the same corner heart.
2. Bag (white law): address strip on top, "via @creator" per line, size+qty
   inline, per-line Wishlist / Remove, offer row + engine bill, footer =
   payment row + the single yellow Place Order.
3. Wishlist: All + collection chips → 2-col grid → Move to Bag (size sheet
   when sized, yellow Add) → toast path to Bag. Long-press assigns to
   collections; active collection chip gets rename/delete via ⋯.
4. First login (Place Order or any OTP moment) adopts the guest wishlist:
   collections recreated, items pushed, links restored; from then on the
   list is the server's live product join — dead products grey out.
5. Food cart, bookings, legacy flows: pixel-identical to before.

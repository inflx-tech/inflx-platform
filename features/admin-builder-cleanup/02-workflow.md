# 02 — Workflow: admin-builder-cleanup

## Admin
1. App Builder → Home → Fashion. Each existing section shows a green **NO RULE** or
   pink **NEEDS A RULE** tag.
2. **Add section** → grouped menu: *Data sections* (no rule), *Frame* (image/banner),
   *Controls*. Food-only presets appear only on the food world.
3. Add **Image / banner frame** → pick a style → add banners. Per banner:
   - upload image,
   - **Create a rule** (Under ₹ · Min % off · Brand · tags · has-offer) or **Use a saved rule**,
   - optionally **Save for reuse** → the rule is saved to the library + the banner wired to it.
4. The **right-side phone** updates live as you configure (real category tiles, real banner
   images in the chosen layout).
5. Publish.

## Follower
- Category rail renders the picked categories + an **"All"** tile (→ the rest).
- Frame banners render in the chosen style; tap → the banner's rule (unchanged engine).

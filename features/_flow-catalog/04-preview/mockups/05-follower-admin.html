5.3 The 4 transaction types F

All paid types use initiate→verify; commission credits influencer pending_balance (30d hold).

① Pay-at-store

  • free-form bill_amount, no cart
  • only Discount-type offers apply
  • optional "pay balance" vs a prior prebook
POST /follower/pay-at-store

② Booking / prebook

  • advance/token only (₹200 default), platform_fee=0
  • writes follower_transactions + follower_bookings (BK######)
  • table/slot/appointment/date_range
  • SLOT_FULL if capacity hit
POST /follower/prebook

③ Online order

  • real cart + delivery address
  • full offer engine (all 5 mechanics)
  • follower_orders: confirmed→dispatched→delivered (brand-driven)
POST /follower/orders

④ Enquiry (lead)

  • no payment
  • enquiry_leads: submitted→responded→converted
  • commission fires only when brand marks converted w/ deal_value
POST /follower/enquiry
Booking brand-status (mig 052): restaurant table bookings start pending (await confirm); others auto-confirmed. Returns (Fashion-1): requested→approved→received→refunded.

2.3 Handpick vs Open-group — the OTHER axis (every set has both a goal AND a mode)

🎯 Handpick (influencer_mode=handpick)

  • Brand searches + picks specific influencers
  • POST /campaigns/:id/sets/:sid/invite per influencer → CI status=invited
  • Per-influencer fee/budget/offer/coupon set at invite
  • Accept → accepted + auto-create draft contract
  • Negotiation ALLOWED

📢 Open-group (influencer_mode=open_group)

  • Brand sets filters (tiers/niches/cities/min_er) + max_cap
  • At publish, materialiseOpenGroupInvites inserts one invited row per match (48h, cap 1000)
  • Accept → applied (NOT accepted, NO contract — it's an application)
  • Brand reviews: approve-application→accepted+contract / reject-application→rejected_by_brand
  • Negotiation FORBIDDEN · cap race → SLOT_FULL → rest become slots_filled

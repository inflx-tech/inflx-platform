# 02 — Workflow: Product Detail rebuild

1. Follower taps a product (Home / Category / Results / creator/brand store) →
   `ProductDetailScreen`.
2. Screen: hero image + back + ♡/share → title (sans-bold) → 5-star rating → brand
   line → optional creator note → price (final + struck MRP + savings if discounted)
   → offer mechanics → colour/size selectors → description → more-from-brand.
3. Sticky CTA bar: per-vertical actions from availing-modes (Pay-at-Store / Book /
   Add-to-Cart), primary gold + ink text, secondaries outlined.

Visual reskin only — all data, variant, offer, CTA, and tracking logic unchanged.

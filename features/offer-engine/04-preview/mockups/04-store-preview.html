◧ The new STORE-DIRECT path new backend

Follower opens store→store offer applied→Buy now→pay · no creator

Today a follower transaction requires the 4 tracking IDs (campaign_id · set_id · offer_id · campaign_influencer_id) — verified in transaction.controller.js. A store-direct sale has no influencer, so this is the one genuinely new flow: make those IDs nullable for store-offer txns, resolve the discount from brand_offers instead of the campaign chain, and write a follower_transactions row with no commission and offer_source='store'.

★ The influencer path is unchanged

Creator link (4 IDs)→store via ?via=→Buy→commission credited

When the same offer is attached to an influencer, the existing tracked flow runs exactly as today — resolveBusinessStore(?via=iid) + commission attribution. No change.

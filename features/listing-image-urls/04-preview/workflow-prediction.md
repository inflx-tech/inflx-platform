# Workflow prediction — Listing Image URLs

**Stepper:** under "Cover photos" (Step ①) and each colour card (Step ②) the
brand sees, beside "Upload from desktop", a **"Paste image URL(s)"** box. Paste
a link (or several, comma-separated), press Add → a moment later the
thumbnail(s) appear exactly like an upload. First cover image = main.

**Excel:** the template has **Cover image URLs** and **Colour image URLs**
columns. The brand pastes their hosted links. After upload, products arrive
**with images**; any link that couldn't be fetched shows in the photo tray as
"N image link(s) couldn't be fetched — add manually", and that product is still
created.

Either way the image ends up in our storage and on the listing — a pasted link
that later breaks at the source won't break the listing.

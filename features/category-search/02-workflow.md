# Workflow — category-search

1. Follower is in a category browser (e.g. Men › Topwear, viewing Polo).
2. Taps ⌕ → the header title becomes a search input ("Search in this category…").
3. Types "cotton" → after a brief debounce the grid shows cotton products from
   the whole current category subtree; pane title = "Results for 'cotton'".
4. Taps ✕ (or back) → search closes, the selected leaf's grid returns.
5. All-categories tiles view + loading view have no search button.

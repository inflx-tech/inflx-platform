Listing and shop safety — four fixes

Most of this round changes what happens, not what a screen looks like. These are the only places where someone sees something different. Dashed red = removed. Green = new.

Fixed with nothing new on any screen
  • Stock 0 saved by a brand is a pause, like Hide: the post waits and returns when you restock.
  • A set with a piece hidden or sold out is not in the shop until the set is whole again. If you allowed pieces to be bought alone, the post stays.
  • Place order makes one order however many times it is tapped for the same attempt.
What does NOT change
  • The Hide and Show buttons, the Edit form's boxes, the checkout, the deal page: the same look.
  • Posts that were removed before this change stay removed.
  • What the shopper reads on a paused post's link: "This post is no longer available", as today.
  • Prices, offers, commissions, wallets and refunds.

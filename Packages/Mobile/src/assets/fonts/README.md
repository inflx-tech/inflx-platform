# Custom Fonts for INFLX Follower App

Download and place the following font files in this directory:

## Syne (Headings)
- `Syne-Bold.ttf`
- `Syne-ExtraBold.ttf`

Download from: https://fonts.google.com/specimen/Syne

## DM Sans (Body)
- `DMSans-Regular.ttf`
- `DMSans-Medium.ttf`
- `DMSans-SemiBold.ttf`
- `DMSans-Bold.ttf`

Download from: https://fonts.google.com/specimen/DM+Sans

## After adding fonts, run:
```bash
npx react-native-asset
```

This links the fonts to both iOS and Android projects.

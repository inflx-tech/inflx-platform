# The Action Map

**Written 2026-09-01.** Every action a person can take in the brand and creator apps, on one
page. This is the spine — the Screen Atlas and the five Action Books hang off it.

**It replaces nothing yet.** The seven tab files stay readable until the Action Books are written,
then they become history.

---

## How to read it

| | |
|---|---|
| **BR-nn** | the brand starts it |
| **CR-nn** | the creator starts it |
| **AD-nn** | admin starts it |
| **⇄** | two people are involved — the action book shows both phones at the same moment |
| **⑂** | the action forks; each branch is written out |

**Verdicts** — 🆕 does not exist · ✎ exists and changes · ✓ works as it is

# What comes next

**1 · The Screen Atlas** — every screen drawn once, with a permanent address. It supersedes the
seven tab files.

**2 · Five Action Books** — one per phase, each action written out with its steps, its forks, both
phones where two people are involved, what it leaves in the data, and what can go wrong.

**3 · The Index** — action → screens, screen → actions, so nothing can be orphaned or described
twice without it showing.

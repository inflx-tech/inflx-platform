Platform Overview 1.1 What INFLX Is INFLX (inflx.in) is a three-sided influencer marketing platform for India, purpose-built for local and regional businesses and micro/nano influencers. Brands create campaigns, assign influencers, set offers. Influencers promote via their social media bio link. Followers discover, book, buy, and pay — all tracked back to the exact campaign, deliverable set, and influencer. 1.2 The Three Sides Role App Primary purpose Brand Web dashboard + Mobile app Create campaigns, assign influencers, fund wallet, review content, view analytics Influencer Mobile app only Receive offers, negotiate, sign contracts, submit content, track earnings Follower Mobile app (web PWA) Discover deals via share link, pay at store, book, buy online, enquire Admin Web dashboard only Approve accounts, manage RBAC, set payment config, view platform stats 1.3 Tech Stack (Locked) Layer Technology Purpose Mobile — Brand + Influencer + Follower React Native iOS + Android from single codebase Web — Brand + Admin React.js (Next.js) SSR for brand web dashboard Backend API Node.js + Express REST API, all business logic Primary database PostgreSQL via Supabase Transactional data, relational schema File storage Cloudflare R2 Content uploads, contract PDFs, images OTP / SMS MSG91 Phone authentication, notifications Payments Razorpay Brand top-up, follower checkout, influencer payouts Social scraping Apify Instagram profile data + post engagement metrics Push notifications Firebase FCM All push notifications across all apps Search Elasticsearch Influencer and product search Cache Redis Session cache, hot queries, rate limiting CDN / Schemas Cloudflare CDN Category schemas, buyer configs, images 1.4 Tracking URL Structure Every share link from an influencer bio carries these parameters: https://inflx.in/s/{influencer_handle}?cid={campaign_id}&amp;sid={set_id}&amp;oid={offer_id}&amp;iid={influencer_id} All follower transactions (pay-at-store, pre-booking, online purchase, enquiry) inherit these four IDs. Commission attribution is automatic — no manual logging needed. 2. Money flows: Follower → INFLX escrow → Brand net + Influencer commission. For brand campaign payouts: Brand wallet → INFLX escrow → Influencer (net of platform fee). 4.2 Brand Wallet Rules Rule Detail Minimum balance to publish Wallet must hold at least the full campaign budget before status can move to published Funds locked on publish Full campaign budget moves to escrow on publish — deducted from brand_wallet_balance Top-up Via Razorpay — UPI, cards, netbanking. Credited instantly on Razorpay webhook confirmation. Low balance alert Push notification fired when available balance &lt; largest single tranche in any active campaign Refund path If campaign cancelled (brand-side) before any content live — full escrow returned to wallet minus platform fee on released tranches 4.3 Tranche Schedule Admin configures global tranche splits in /admin/config/payments. Brand can request override — admin approves per-campaign. Tranche Default split Trigger event Processing time Notes Tranche 1 25% Both parties sign contract Within 24 hours of both signatures Minimum fee guarantee — ensures influencer starts work Tranche 2 25% Brand confirms content Live Within 24 hours of live confirmation Fires after brand clicks &quot;Confirm live&quot; in File 04 Tranche 3 50% 30 days after Tranche 2 trigger Automatic — no action needed Return window closes — commission also confirms on this date 4.4 Platform Fee Calculation Item Who pays When deducted Default rate Platform fee Brand only (influencer receives full agreed fee) Per tranche payout 8% of influencer fee per tranche Example: Fee ₹40,000 agreed Brand wallet holds ₹40,000 + 8% = ₹43,200 T1: ₹10,000 paid to influencer, ₹864 platform fee. T2: ₹10,000 + ₹864. T3: ₹20,000 + ₹1,728 Total platform revenue: ₹3,456 IMPORTANT: Platform fee is charged to the BRAND — added on top of the agreed influencer fee. Influencer always receives the exact agreed amount minus TDS at withdrawal. The fee is NOT deducted from influencer payout. 4.5 Follower Transaction Calculations 4.5.1 Pay-at-store (percentage discount) net_amount = gross_amount × (1 - discount_pct/100) influencer_comm = net_amount × commission_pct/100 platform_fee = net_amount × brand.platform_fee_pct/100 brand_net = net_amount - influencer_comm - platform_fee 4.5.2 Online order (flat discount) net_amount = sum(item_prices) - flat_discount_value influencer_comm = net_amount × commission_pct/100 platform_fee = net_amount × brand.platform_fee_pct/100 brand_net = net_amount - influencer_comm - platform_fee - delivery_fee 4.5.3 Pre-booking (advance payment) advance_paid = offer.prebook_advance commission_on_advance = advance_paid × commission_pct/100 brand_receives_advance = advance_paid - commission_on_advance - platform_fee balance_at_venue = (total_bill × (1 - discount_pct/100)) - advance_paid 4.6 Influencer Withdrawal — TDS Rules Rule Detail TDS rate 10% on every withdrawal per Indian Income Tax (Section 194M) Deduction timing At withdrawal — not at earning time. Influencer sees gross earnings, deduction shown on withdrawal screen. Minimum for TDS TDS applies on all withdrawals — no threshold Form 16A INFLX issues Form 16A annually (April) covering all TDS deducted in the financial year Minimum withdrawal ₹100 net (gross = ₹112 approx with TDS) Formula tds = amount_requested × 0.10 | net_paid = amount_requested - tds 4.7 Commission Return Window State Condition Action Commission pending follower_transaction.status = completed AND now() &lt; return_window_ends_at Commission in influencer.pending_balance. Cannot withdraw. Commission confirmed now() &gt;= return_window_ends_at AND status = completed Auto-job moves pending_balance → wallet_balance. Influencer can withdraw. Commission reversed follower returns item → status = returned Commission reversed from pending_balance. brand_net refunded to brand wallet. A daily cron job (00:01 IST) scans follower_transactions where return_window_ends_at &lt;= now() and status = completed and commission_confirmed_at IS NULL. Moves commission to influencer wallet_balance. 5.
